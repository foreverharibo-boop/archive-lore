# Archive Lore · 아카이브 로어

[Memory Books](https://github.com/aikohanasaki/SillyTavern-MemoryBooks)를 기반으로 UI와 실행 흐름을 개편한 포크입니다.

- 채팅방에서 마지막 수집 위치 다음부터 버튼 한 번으로 수집
- 메시지 수·토큰 수 기준 자동 수집 · 버퍼 없음 · 지난 대화 범위 분할 수집
- 수집·임베딩 성공 후 자동 숨김 · 최근 수집 메시지 보존 개수 입력
- 기억 → 아크 → 통합 아크 · 짧게 다듬기·원문으로 다시 만들기 · 초안 확인 후 적용
- 수집 후 별도 API 키로 자동 임베딩 · 실패한 임베딩만 재시도
- **대화로 검색 / 질문으로 검색** 후 필요한 원문만 선별해 주입
- 영어 기억 요약: 제목 + 날짜·장소 한 줄 + 사건 문단
- 관계·약속·취향·감정·전환점·계획을 **6개 개별 사이드 항목**으로 저장하고 변경된 내용만 갱신
- 사이드별 프롬프트·이름 편집, 켜기·끄기, 사용자 항목 추가 · 켠 항목은 기억 수집과 같은 요청으로 실행
- 관계·이별·재회 D+를 RP 날짜로 계산 · 날짜 직접 수정 가능
- 변경 전 사이드 기록 보존 · 기본 프롬프트 편집 및 가져오기/내보내기
- AI Studio / Vertex 임베딩 키 직접 입력 · 기본 모델 자동 적용 · 실제 API 오류 표시
- 서버 플러그인: 브라우저 종료 후에도 접수된 수집·임베딩·검색·기억 정리 계속 실행
- 서버 작업·벡터·진단·초안 저장 및 재접속 후 확인
- 턴별 검색·선별·주입 진단 기록과 TXT 다운로드
- 로어북 매니저의 기존 번역 표시 · 프롬프트 전체화면 편집
- SillyTavern 테마를 따르는 모바일 UI · 슬래시 명령어

**0.4.1 UI 보완:** 앞쪽 펼침 세모를 제거하고 오른쪽 +/−로 표시합니다. 주인공 이름은 14px로 줄이고, 사이드 설정 행·목록·상하 여백을 더 작게 정리했습니다. 테마가 겹쳐 검색창 테두리가 이중으로 보이거나 수집 버튼 글씨가 흐려지는 현상을 방지합니다.

**0.4.0 UI:** 기억 / 사이드 / 최근 주입 탭, 하단 고정 수집 버튼, 별도 도구 화면과 공통 선 아이콘으로 정리했습니다. 확장 설정은 연결 / 수집·검색 / 프롬프트 / 서버로 나눴고, 채팅창 설정 버튼에서도 열 수 있습니다. 색상은 SillyTavern 테마를 따릅니다. 이번 화면 변경은 확장 업데이트 후 브라우저 새로고침으로 적용되며 서버 플러그인 재시작은 필요하지 않습니다.

설치 주소: `https://github.com/foreverharibo-boop/archive-lore`

## 처음 사용하기 · 메모리북과 설정 공유

새로 설치하면 **아카이브 검색·주입은 기본적으로 꺼져 있습니다.** 검색 연결과 임베딩을 준비한 뒤 설정의 **아카이브 검색·주입 활성화**를 켜 주세요. 꺼진 동안에는 아카이브의 별도 검색·주입 경로를 사용하지 않으며, 기본 로어북 발동 경로를 사용합니다. 기억 수집·관리는 계속 사용할 수 있습니다. 이미 사용 중인 분의 저장된 켜짐·꺼짐 설정은 업데이트 후에도 유지됩니다.

아카이브 로어는 원본 Memory Books와 **설정 저장 영역, 채팅별 수집 정보, 요약·통합·사이드 프롬프트 파일을 공유**합니다. 별도로 분리된 설정 사본을 만드는 방식이 아니므로, 아카이브 로어에서 저장한 변경이 나중에 원본 메모리북을 사용할 때도 반영될 수 있습니다. 두 확장을 동시에 활성화하지 말고 사용할 확장 하나만 켜 주세요.

아카이브 로어는 **수정하지 않은 기본 프롬프트를 영어 기록용 기본값으로 바꿔 저장할 수 있습니다.** 이 변경은 원본 메모리북으로 돌아가도 남을 수 있습니다. 직접 수정한 프롬프트는 보존하지만, 전환 전에 필요한 프롬프트는 내보내기로 백업해 두는 것을 권장합니다. **오리지널 메모리북 화면** 옵션은 화면 구성을 바꾸는 기능이며, 설정을 분리하거나 아카이브 기능을 전부 끄는 옵션은 아닙니다.

[설치·동작·제한 사항](userguides/1%20Memory_Books_AI_Reference_Manual.md) · [기본 프롬프트](prompts/archive-lore-defaults.json)

**0.4.1:** 자동화·브라우저 모의 검사는 완료했으며, 실제 모델의 기억 수집 품질과 사용자 SillyTavern 환경에서의 검증은 아직 필요합니다.

서버 플러그인은 같은 저장소를 SillyTavern의 `plugins/archive-lore-server`에도 설치합니다. 확장과 서버 복사본을 함께 업데이트해 주세요. [설치 명령·서버 모드 안내](userguides/1%20Memory_Books_AI_Reference_Manual.md#server-plugin-installation-and-lifecycle)

**0.3.2:** 많은 기존 기억을 한꺼번에 코어에서 해제한 뒤 목록이 비는 문제를 수정했습니다. 임베딩 상태를 묶어서 확인하고 중복 새로고침을 합칩니다. 서버 플러그인도 업데이트하면 일괄 조회를 사용합니다.

**0.3.1 정정:** Vertex 임베딩을 일괄 차단한 0.3.0 처리를 제거했습니다. AI Studio는 API 키, Vertex는 API 키·Google Cloud 프로젝트 ID·리전(기본 `global`)으로 요청합니다. 해당 요청 경로를 Archive Lore 안에 독립적으로 구현했습니다. 기억 작성·검색 프로필과 임베딩 설정도 구분했습니다. 두 제공자의 요청·응답 모의 검사를 통과했으며 실제 키 권한·한도는 연결 확인으로 점검해 주세요.
